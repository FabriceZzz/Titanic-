# Titanic 泰坦尼克号生存数据分析 (EDA)

本项目是基于 Kaggle 泰坦尼克号（Titanic）数据集进行的探索性数据分析（EDA）。
项目目标是通过数据清洗与可视化，挖掘影响乘客生存率的关键因素，并为后续的 AI 模型开发与 MLOps 部署打下数据基础。

## 📊 数据集说明
- **数据来源**：[Kaggle - Titanic Dataset](https://www.kaggle.com/c/titanic)
- **数据规模**：891 行 × 12 列
- **包含特征**：乘客ID、是否生存、客舱等级、姓名、性别、年龄、兄弟姐妹/父母子女数量、票价、登船港口等。

### 数据清洗策略
通过观察数据缺失情况，本项目采取了以下清洗策略：
1. **`Cabin`（客舱号）**：缺失率高达 77.10%，直接删除该列。
2. **`Age`（年龄）**：缺失 177 条（19.87%），使用**中位数**进行填充。
3. **`Embarked`（登船港口）**：缺失 2 条（0.22%），使用**众数**进行填充。
4. 清洗后，数据集无任何缺失值，为后续分析提供干净的数据源。

## 💡 核心分析洞察
经过数据可视化分析，各特征对生存率的影响程度排序如下：

1. **性别（Sex）—— 区分度极强**
   - 女性生存率高达 **74.2%**，男性生存率仅为 **18.9%**。
   - 女性生存率约为男性的 **3.9 倍**，完美契合了当时“女士儿童优先”的救援原则。
2. **客舱等级（Pclass）—— 强相关性**
   - 1 等舱生存率：**63.0%**
   - 2 等舱生存率：**47.3%**
   - 3 等舱生存率：**24.2%**
   - 生存率随客舱等级下降呈单调递减，社会阶层与资源获取能力对生存有决定性影响。
3. **票价（Fare）—— 中等相关性**
   - 生存组的票价中位数明显高于死亡组，高票价（多为头等舱）乘客生存概率更大。
   - 但票价与客舱等级存在共线性，建模时需注意处理。
4. **年龄（Age）—— 非线性弱相关**
   - 儿童（0-10岁）在生存群体中占比突出，青壮年（20-35岁）在死亡群体中占比较高。
   - 由于箱线图重叠较大，单变量区分度较弱，后续建模建议将其分箱或与性别特征交叉。
